📱 Pinephone

I haven't had a "regular" normal phone for the last ~3 years. Usually I just do without but recently I've been trying to use a pinephone as my daily driver. It isn't going super well; here I list some of my experiences in the hopes that someone can point me in the right direction for how to use this hardware.

Operating system and window manager

I've installed SXMO running Arch Linux from an image put together by DanctNIX. I really like the ideas here. The usual pinephone woes are hitting me as expected: poor battery life and not very beefy performance.

One thing that's worked well is keeping the phone awake by sshing into it while the screen goes off. This reduces the heat and power consumption significantly and still lets me use it as a normal device.

Quick fixes

I should probably report these to the maintainers, they both seem like oversights.

Screen off, suspend not working

Install package wlopm.

LED not working (and also wake/suspend state changes taking a long time)

Add your user (probably alarm) to the group feedbackd.

Firefox

By default firefox has some issue where it won't allow you to make the screen smaller than a certain width, which is awkward because the pinephone's horizontal resolution is only 384px! But it turns out you can install a mobile config for firefox package from the arch repos. This seems to mostly just work, although having the keyboard up partly obscures the url bar (not the keyboard itself, it just causes half of the url bar to turn white).

Calendar

Finally I can have a calendar that works! (Usually I have a paper calendar in the form of a small notebook but I forgot to buy one this year and things have been a bit hectic.) gnome-calendar is lightweight and snappy enough for me. It has some bugs but nothing terrible, again probably it's not tested with the narrow screen I'm using. I did get my AI to fix one, which was that days with events scheduled wouldn't show any events on the calendar view: you would have to click on each individual day to see any events scheduled for that day!

Sadly I can't upstream this change even though it was very quick, because gnome-calendar apparently doesn't allow AI contributions. Maybe at some point I will try to understand that part of the code and clean-room my own fix. Possibly it's not even considered a bug for some reason.

It is not super snappy and there are other minor issues as I've said (sometimes you can't edit or delete some events), so I might in the end try to vibe code a lightweight terminal calendar, maybe using the special dmenu thing sxmo has.

Trusted vs untrusted connections

This is something I've set up on my laptop too: I keep a list of "trusted" network profiles. When connecting to an untrusted profile two things happen: the MAC address randomises, and avahi stops advertising itself over mDNS. When moving back to a trusted profile the MAC resets and avahi starts back up. I'm not a linux or networking expert so I was pretty excited that now with avahi and mDNS I can ssh user@hostname.local instead of having to use the local IP address which might change sometimes anyway.

I've done a lot of home networking configuration recently (will probably write about that in a different post); I've learned a lot about these things but still feel like I'm hardly scratching the surface.

Minor complaints

  • the power button only registers intermittently. E.g. when I press it twice to wake up, about half the time it only wakes into the "touch disabled" state and I have to press the button again to wake it fully.
  • the menu UI is a bit inconsistent: two menus looking the same don't necessarily both take control of the physical buttons in the same way (i.e. so that volume up/down move selection up and down, etc). The system menu does, as do the apps and scripts menus, but the binaries menu doesn't for some reason. Also the "back" option in a menu is sometimes at the top, sometimes at the bottom, and sometimes absent; likewise for the "exit" option.
  • sluggish: the pinephone is generally slow, but the time from button press -> menu appear feels really long and I don't know why. Likewise for changing between menus: there is quite a long pause between one menu disappearing and another opening.
  • other things I can't remember right now
