Using Quassel IRC
2026-10-07
Tags: irc

I've set up Quassel to join some IRC channels I was interested in. Finally! IRC has always scared me and I've only just now started using it in a reasonable way - previously I tried using an ephemeral web client but whenever I shut my laptop it would stop receiving messages, which was a bit silly.

One strange thing with Quassel is that the client doesn't load all messages, I have to scroll down for the shown messages to go further back in time (which is in the upwards direction, since recent messages appear at the bottom). I tried changing the number of recent shown messages from 200 to 2000 but that just seemed to make it hang for a long time.
